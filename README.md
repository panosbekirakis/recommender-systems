# Recommender Systems — MovieLens 10M

## Project Overview
Matrix Factorization with SGD and Collaborative Filtering 
on the MovieLens 10M dataset.

## Structure
- `Part 1` — Following standard approach (Basic SGD)
- `Part 2` — Extended approach (Bias terms, Early stopping, Filtering)

## Dataset
Download MovieLens 10M from:
https://grouplens.org/datasets/movielens/10m/

## Results
| Model | RMSE |
|---|---|
| Part 1 Baseline | 1.2197 |
| Part 1 Tuned | 1.0242 |
| Part 2 Best | 0.8104 |
